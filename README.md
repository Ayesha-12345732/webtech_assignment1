# Ayesha Rani - HTML Resume

## 📌 Project Description

This project is a simple resume webpage created using **HTML**.
It presents my personal profile, education, work experience, projects, skills, and languages in a clean and organized format.

## 🛠️ Technologies Used

* HTML5

## 📄 Sections Included

* Profile Summary
* Education
* Work Experience
* Projects
* Skills, Tools & Technologies
* Languages
* Contact Information

## 🎯 Purpose

The purpose of this assignment is to practice the **basic concepts of HTML**, including headings, paragraphs, lists, tables, text formatting, and HTML entities.
